# Pandas Sales Data Analysis

## 📌 Project Overview
This project focuses on cleaning and analyzing sales data using Python and Pandas. The goal is to handle missing values, prepare the dataset, calculate sales metrics, and generate useful business insights.

## 🎯 Objectives
- Clean the sales dataset and handle missing values.
- Analyze sales and order information.
- Calculate gross sales, discount amounts, and net sales.
- Identify top-performing categories, products, and cities.
- Analyze monthly sales trends.
- Generate business recommendations based on the data.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- CSV Dataset

## 📊 Project Tasks
1. Load and explore the dataset.
2. Identify and handle missing values.
3. Check and correct data types.
4. Calculate gross sales, discounts, and net sales.
5. Analyze completed-order revenue.
6. Identify the top category, product, and city.
7. Summarize monthly sales trends.
8. Export the cleaned dataset to CSV.

## 📁 Project Files
- `Sales_Analysis.ipynb` — Jupyter Notebook containing data cleaning, calculations, and analysis.
- `cleaned_sales_dataset.csv` — Cleaned sales dataset exported from Pandas.

## 💡 Business Insights
The analysis is designed to identify sales performance, top-performing products and categories, city-wise sales, and monthly trends.

## 🚀 How to Run
1. Download or clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy jupyter
   ```
3. Open the notebook in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.
